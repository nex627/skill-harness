# 视频制作

## 定位

**视频制作的多步骤流水线 skill。**

把做视频拆成四步：调研 → 策划 → 制作 → 发布。每步产出需要人工检查通过才进下一步。发布后数据自动收集，经验沉淀到知识库。

## 触发规则

| 触发词 | 说明 |
|--------|------|
| 做视频、发视频 | 启动完整流程 |
| 视频选题 | 仅步骤1 |
| 写视频脚本 | 仅步骤2 |

## 知识库

| 层级 | 路径 | 用途 |
|------|------|------|
| L2 行业库 | `L2/video/best-practices.md` | 平台规则、爆款结构 |
| L3 私有库 | `L3/video-production/history.md` | 历史发布数据、踩坑记录 |

---

## P 阶段 — 规划（执行前必做）

**读取历史经验**：
- 读取 L3 历史发布数据（最近10条 + 爆款复盘）
- 读取 L2 平台规则和爆款结构
- 读取 L1 通用内容方法论（可选）

**产出**：执行方案（选题方向 + 目标数据 + 参考对标）

---

## D + C 阶段 — 按步执行 + 人工检查

### 步骤1：调研（竞品视频分析 + 选题）

- **输入**：账号定位 + 历史数据
- **动作**：
  1. 搜索同类账号近期爆款（≥3个）
  2. 分析爆款结构（钩子/节奏/话题）
  3. 结合账号定位确定选题
  4. 整理参考视频清单
- **产出**：选题报告 + 参考视频清单

**检查点**（人工检查）：

| 检查项 | 标准 |
|--------|------|
| 选题匹配 | 符合账号定位 |
| 对标覆盖 | ≥3个参考视频 |
| 差异化 | 与对标有区分点 |
| 数据预期 | 有合理的数据目标 |

> ✅ 通过 → 进入步骤2
> ❌ 不通过 → 返回步骤1重新选题

---

### 步骤2：策划（脚本 + 分镜）

- **输入**：步骤1的选题报告
- **动作**：
  1. 写完整脚本（开场钩子3秒 + 正文 + 结尾引导）
  2. 设计分镜（≥5个，每个含画面/文字/时长）
  3. 确定 BGM 风格和节奏点
  4. 设计互动引导（评论区话术）
- **产出**：完整脚本 + 分镜表

**检查点**（人工检查）：

| 检查项 | 标准 |
|--------|------|
| 钩子有力 | 前3秒能留住人 |
| 逻辑完整 | 有起承转合 |
| 可执行 | 拿着脚本能直接拍 |
| 互动设计 | 有明确的互动引导 |

> ✅ 通过 → 进入步骤3
> ❌ 不通过 → 返回步骤2修改脚本

---

### 步骤3：制作（拍摄/生成 + 剪辑）

- **输入**：步骤2的脚本 + 分镜表
- **动作**：
  1. 按分镜拍摄或生成画面
  2. 剪辑拼接
  3. 添加 BGM、字幕、特效
  4. 调整节奏和时长
- **产出**：成片

**检查点**（人工检查）：

| 检查项 | 标准 |
|--------|------|
| 画面质量 | 清晰、构图合理 |
| 节奏 | 不拖沓，与BGM配合 |
| 字幕 | 无错别字、位置正确 |
| 时长 | 符合平台最佳时长 |

> ✅ 通过 → 进入步骤4
> ❌ 不通过 → 返回步骤3修改

---

### 步骤4：发布策略（标题/标签/封面）

- **输入**：步骤3的成片
- **动作**：
  1. 写标题（≥3个候选，选最优）
  2. 选话题标签（≥3个）
  3. 设计封面
  4. 确定发布时间
- **产出**：发布方案

**检查点**（人工检查）：

| 检查项 | 标准 |
|--------|------|
| 标题 | 有点击欲，不含标题党 |
| 标签 | 覆盖目标关键词 |
| 封面 | 清晰、有吸引力 |
| 发布时间 | 符合目标受众活跃时间 |

> ✅ 通过 → 发布 + 进入 A 阶段
> ❌ 不通过 → 返回步骤4修改

---

## A 阶段 — 经验沉淀

| 步骤 | 动作 | 产出 |
|:---:|------|------|
| 1 | 发布后48小时系统自动收集数据（播放量/完播率/互动率） | 数据报告 |
| 2 | 收集人工反馈（哪个环节卡了、什么没做好） | 反馈清单 |
| 3 | 爆款模式提取（如有）→ 写入 L3 | 经验入库 |
| 4 | 踩坑记录写入 L3（≥3条）+ 版本号 | 版本记录 |

---

## 五大设计约束

1. **多步拆解** — 调研→策划→制作→发布，四步不可合并
2. **人工检查点** — 每步通过才进下一步
3. **明确产出** — 选题报告/脚本/成片/发布方案，每步有实物
4. **经验沉淀** — 系统自动收集数据 + 人工反馈 → L3 知识库
5. **历史复用** — 执行前读取历史数据，避免重复踩坑

## 禁忌

- 禁止跳过调研直接写脚本
- 禁止跳过脚本直接拍
- 禁止跳过检查点
- 禁止发布后不复盘
