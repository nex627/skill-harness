# 示例：抖音内容运营 Skill

这是一个使用 Skill Harness 创建的 **Workflow Harness 型** skill 示例。

## 创建过程

```
用户 ❯ 帮我为抖音内容运营创建一个 skill

Skill Harness ❯ 启动 PDCA 流水线...

【P 阶段】
- 读取历史：无（首次创建，标记放行）
- 行业对标：搜索抖音运营最佳实践，找到3个对标
- 模板选择：Workflow Harness 型（需要 PDCA 闭环）
- 产出：选题调研报告 + 内容目标 + 选题方案

【D 阶段】
- D1 执行摘要：选题逻辑 + 目标受众 + 钩子设计
- D2 详细定义：完整 SKILL.md（见同目录 SKILL.md）
- D3 偏差记录：无偏差

【C 阶段】
- AI 自检：格式 95 / 逻辑 90 / 可用性 88 / 边界 85 → 综合 89.5 ✅
- 人工复核：通过 ✅

【A 阶段】
- 版本号：v1.0.0
- 踩坑记录：首次创建，暂无
- 写入 L3：已沉淀
```

## 使用方式

将 `SKILL.md` 复制到你的 AI Agent 的 skills 目录，然后：

```
> 发抖音
> 帮我做个抖音选题
> 复盘上周抖音数据
```
