**{领域}决策 skill。** 知识库驱动，skill 是调用者，知识库是大脑。

不是凭通用知识回答，是读取知识库 → 匹配决策表 → 输出有依据的建议。

## 触发规则

当用户提到以下关键词时触发：

- {关键词1}

**强制前置规则**：触发时必须先读取知识库文件，再输出任何建议。不读取就回答 = 质量不合格。

## 知识库

| 知识库 | 路径 | 用途 |
|--------|------|------|
| 主知识库 | `{path}/main.md` | 核心决策逻辑、框架 |

### 读取规则

```
1. 先读主知识库（必须）
2. 用户问题涉及关联领域时，读取关联知识库
3. 基于知识库内容 + 用户画像输出建议
```

## 决策流程

```
用户输入
  ↓
意图识别 → 匹配决策表
  ↓
读取知识库（主 + 关联）
  ↓
匹配决策框架
  ↓
输出建议（含依据 + 退出条件）
  ↓
记录到日志
```

## 输出规范

每条建议必须包含：

| 要素 | 说明 |
|------|------|
| **建议** | 具体做什么 |
| **依据** | 基于知识库的哪条规则 |
| **退出条件** | 什么情况下这个建议失效 |
| **关联** | 涉及哪些其他知识库 |

**禁止**：无依据的建议、笼统的"看情况"。
